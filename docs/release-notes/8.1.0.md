## ☁️ Game Saves

- **Online-only OneDrive saves are backed up.** When a save is in OneDrive but only in the cloud and OneDrive is not running, the backup now starts OneDrive, waits for the files to come down and backs those games up again. This also works for scheduled backups. Before, these games failed with *"The cloud file provider is not running"*.
- **Clearer failure details.** Games that fail for the same reason are grouped under that reason, and each game shows the file involved, instead of the same long message repeated for every game.

## 🎨 Look and feel

## 🧷 Setup and shortcuts

- **Your shortcut choices are remembered** and offered again the next time you run the setup.
- **Updates respect what you did:**
  - a shortcut you chose that never got created is tried again;
  - one you deleted stays deleted.
- **No more duplicate Start menu entries:** a broken shortcut, or one left behind by an older copy of the app, is replaced instead of getting a second entry beside it.
- **More reliable shortcut creation:** each shortcut is retried a few times. If Windows still refuses one, the install finishes anyway and the last screen tells you which one is missing.
- **Missing Start menu entry fixed:** installs that lost it get it back with this update.

## 🚀 Start with Windows

- **Off by default.** Nothing needs it: Game Saves' scheduled backups run on their own, from a scheduled task, without opening the app.
- **Switch it on or off in Settings → Appearance**, without running the setup again.
- **Start minimized:** choose whether the app waits in the taskbar or opens on screen when Windows starts it. The option is in Settings, and in the setup under "Start with Windows" (*Minimized / On screen*).

> If the app started with Windows before and you do not want that, switch **Start with Windows** off in Settings once. Updates keep that choice.
