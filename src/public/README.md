# Εικονίδια που ταξιδεύουν με την εφαρμογή

Ό,τι βάλεις εδώ μπαίνει στο build και το βλέπουν όλοι οι χρήστες.

Ένα αρχείο `src/public/icons/billias.svg` το δηλώνεις στη λίστα ως:

```json
"icon": "/icons/billias.svg"
```

- **SVG**: η καλύτερη επιλογή για λογότυπα. Παραμένει καθαρό σε κάθε ανάλυση και είναι μικρό.
- **PNG ή WebP**: για εικόνες με φωτογραφικές λεπτομέρειες. Βάλε 256×256 με διαφάνεια.
- Το εικονίδιο εμφανίζεται σε ~46 px, οπότε μεγαλύτερο από 256 px δεν χρειάζεται.

Εναλλακτικά, στο `icon` μπορείς να βάλεις και:

- πλήρες `https://…` URL
- διαδρομή αρχείου στον υπολογιστή, π.χ. `C:\Users\Thomas\Pictures\logo.png` ή `%USERPROFILE%\Pictures\logo.png` (μόνο για εσένα, το διαβάζει το backend)
